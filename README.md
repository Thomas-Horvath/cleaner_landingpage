# Cleaner Landing Page

Statikus Next.js alap egy magyar nyelvű takarítási bemutatkozó oldalhoz, külső online foglalási integrációra felkészítve.

## Fejlesztés

```bash
npm run dev
```

## Build

```bash
npm run build
```

Az alkalmazás `output: "export"` módban működik, így a build eredménye statikus tárhelyre is kitehető.

## Dokumentáció

A projekt induló dokumentációja a [`docs`](./docs) mappában található.
